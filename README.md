## Run the local story workspace

Use Node.js 22.18 or newer. Run `npm ci`, then `npm run dev`. Open `http://localhost:3000`. The local preview uses prepared stories, simulated collaborators and browser-local resource accounting.

Run `npm test` and `npm run typecheck` to verify the implemented modules.

The separate image experiment tools preserve attempt records and bounded expense accounting. Paid execution requires deliberately supplied provider credentials.

The `/pilot` route connects named Supabase guests, shared stories and Trigger generation. Configure the ignored `.env.local` from `.env.example`, apply the Supabase migrations and seed, and run `npm run dev:worker`. Provider allowances begin disabled.

Prepared story and creator review experiences are available at `/world-demo` and `/creator-demo`; `/demo` and `/signup` support demonstrations. [Boat-demo feedback](docs/submission/BOAT-DEMO.md) records the founder's recollection.

The original Midnight Signal room supports a registered, frozen Monad testnet release with an explicitly disclosed equal-wallet policy. [The onchain guide](docs/submission/ONCHAIN.md) documents the verified deployment and founder-operated payment/claim rehearsal.
